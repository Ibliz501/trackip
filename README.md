🔥 Tentang TrackIP

TrackIP adalah tools sederhana namun powerful untuk melakukan tracking informasi IP secara cepat dan efisien.
Dibuat dengan Python dan dirancang agar ringan, mudah digunakan, dan tetap terlihat keren.

---

⚡ Fitur Utama

- 🌍 Tracking IP Address
- 📡 Informasi Lokasi (Negara, Kota, dll)
- ⚙️ Simple & Fast
- 🖥️ CLI Friendly 

---

pkg update && pkg upgrade

pkg install python git
